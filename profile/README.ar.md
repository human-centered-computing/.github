# Human-Centered Computing

[English](README.md) · [Türkçe](README.tr.md) · [Deutsch](README.de.md) · [العربية](README.ar.md)

> هذه خلاصة مترجمة قيد المراجعة وليست ترجمة كاملة. يرجع إلى [المصدر الإنجليزي](README.md) للتفاصيل ومعايير القبول.

Human-Centered Computing مجتمع دولي للبحث والتطوير مفتوح المصدر أسسه Murat Delen. يربط المعرفة الأكاديمية بالحياة اليومية بالبحث المتعدد التخصصات والتعاون المسؤول بين الإنسان والذكاء الاصطناعي والعلم المفتوح ومبادئ Industry 5.0. دورة العمل: مشكلة واقعية وتحليل وتصميم تحول بشري وتجارب قابلة للقياس وبرمجيات ونماذج واختبار واقعي ونشر مفتوح مسموح ومراجعة علمية وتطوير دولي. الأولوية للكرامة والسلامة والقرار البشري. المجالات: الذكاء الاصطناعي البشري وComputing/Education/Agriculture/Politics 5.0 والكوارث والمدن والخدمات العامة والقانون والصحة والاستدامة والتحول المؤسسي. مشاريع بارزة: RetinexTapetum وTapetum Sentinel المخطط وPolitics5 وNextLife بجامعة حران وNextDeveloper. التعليم يجمع المعرفة والهندسة والبحث والأخلاق والتعاون. الإنجليزية مرجعية، والتركية والألمانية والعربية مدعومة واللغات الإضافية محفوظة. AGPL-3.0 افتراضي للأعمال الأصلية مع تراخيص الأصل؛ لا نشر دون الشروط القانونية والأخلاقية والخصوصية والأمن. المساهمات في البحث والشفرة والتصميم والاختبار والترجمة والتوثيق؛ العضوية والصلاحيات والموافقة والمساهمة أمور مستقلة.
